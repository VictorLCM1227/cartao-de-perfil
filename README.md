# Cartão de Perfil

## Sobre o projeto

Um cartão de perfil desenvolvido para apresentar informações pessoais e profissionais de forma simples, visual e organizada.

A ideia é criar um componente que possa ser utilizado como uma pequena apresentação pessoal na web.

## Objetivo

Praticar HTML e CSS através da criação de um layout compacto, trabalhando principalmente com estrutura, posicionamento, espaçamento e estilização.

## O que pretendo colocar

* [ ] Foto de perfil
* [ ] Nome
* [ ] Descrição pessoal
* [ ] Área de atuação
* [ ] Localização
* [ ] Links para redes profissionais
* [ ] Botão de contato
* [ ] Ícones de tecnologias/conhecimentos
* [ ] Efeitos de hover
* [ ] Design responsivo

## Tecnologias

* HTML5
* CSS3

## O que vou praticar

* HTML semântico
* Flexbox
* Box Model
* Tipografia
* Cores e gradientes
* Bordas e sombras
* Pseudo-classes
* Efeitos de `hover`
* Responsividade
* Organização de CSS
